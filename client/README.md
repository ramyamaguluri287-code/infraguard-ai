# 🌐 InfraGuard AI — Frontend Client

This is the React 18 + Vite frontend for the **InfraGuard AI Command Center**.

## 🚀 Features

- **Cyber Dark Glassmorphic Design**: Built with Tailwind CSS and custom gradient utilities.
- **Leaflet Spatial Intelligence (GIS)**: Multi-layer map engine (Dark, Satellite, Topographic) with dynamic infrastructure risk pins.
- **AI Computer Vision Studio**: Interactive HTML5 bounding box defect detection with confidence tags and custom image upload.
- **Predictive Forecaster**: 0–24 month non-linear deterioration curves and cost escalation models using Recharts.
- **Autonomous Drone Fleet**: Real-time telemetry feed for UAV LiDAR, Thermal, and Submerged Sonar crawlers.
- **Multimodal Data Fusion**: Synthesizes CV detections, strain/moisture IoT sensors, and 311 citizen logs.
- **Knapsack Resource Prioritizer**: Budget-constrained dispatch scheduler.
- **Official Work Order Generator**: Civil engineering reports with one-click print/export.

## ⚙️ Development

```bash
# Install dependencies
npm install

# Start Vite dev server on port 5173
npm run dev

# Build production bundle
npm run build
```
